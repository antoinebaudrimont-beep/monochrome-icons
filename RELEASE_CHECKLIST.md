# v0.1.1 release scope

Only included artwork is covered by this release. Unresolved assets are omitted, not declared cleared. Remaining coverage/integration work belongs in the roadmap.

- [x] Per-asset source verification and license/credit records for the distributed subset.
- [x] Full required license texts and retained upstream notices.
- [x] Omitted artwork excluded from source, built package and previews.
- [x] Freedesktop icon-theme index, ten fixed PNG sizes and explicit fallback themes; editable SVGs retained.
- [x] Source-specific MX Viewer review, GPL notices and credits; 35 other unresolved entries omitted.
- [x] Portable native-name mappings for supported Plank/system-launcher consumers; no profile IDs exported.
- [x] Optional Xfce Weather companion at 22/48/128 pixels.
- [x] Conservative installer with dry-run, per-user backups and conflict-aware restore.
- [x] Portable opt-in launcher/category mapping; commands and existing dynamic calendars preserved.
- [x] Clean artwork-only phone-friendly previews and documented installation/restore.
- [x] Isolated installer/builder tests, source-pixel comparisons, integrity/privacy and GTK/Qt theme lookup checks.

The release checker and tests must pass immediately before tagging or publishing.
